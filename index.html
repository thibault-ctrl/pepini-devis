Règles métier

Une règle par ligne. Claude lira ce texte et l'appliquera à chaque devis. Tu peux modifier, supprimer ou ajouter n'importe quelle ligne.

Architecture du pipeline IA

Le devis client passe par un pipeline n8n en 5 étapes :

  1. Identification Claude : extrait genre, cultivar, taille, hauteur de chaque plante
  2. Recherche multi-source : embeddings OpenAI + recherche vectorielle pgvector + queries SQL ciblées (PIDF + cultivar)
  3. Application des règles métier : surcharge cultivar/fournisseur selon les règles définies
  4. Scoring : bonus genre, taille, couleur, PIDF, cultivar match
  5. Choix final : Claude rerank + override PIDF/couleur + fallback genre
